# Vacancy Research Assistant — OAuth Callback

Static HTTPS callback page for the HeadHunter OAuth flow used by a personal job-search application.

## Redirect URI

```
https://miko0085.github.io/hh-api-callback/callback.html
```

The page accepts the standard OAuth query parameters such as `code` or `error` and shows a simple status message.

No client secret or access token is stored in this repository.
